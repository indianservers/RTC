## Actual training and measurement

Commands executed in .venv-english with PYTHONPATH=backend:

```
python training/english/train.py --pilot --tensorflow --epochs 8
python scripts/benchmark_english_nlp.py
```

Pilot-v2 trained on 63 unreviewed English rule phrases over 44 classes, eight TextCNN epochs. SVM training-only macro-F1: 1.0000. TextCNN training-only macro-F1: 0.15647. These are resubstitution scores and cannot establish generalization, independent accuracy or production readiness. The tiny corpus supplies only about one or two phrases per intent; many real questions, negatives, corrections and out-of-scope examples are absent. TextCNN underfits badly. Increasing training accuracy alone would not solve the missing evaluation evidence. A benchmark query containing negated AC was classified as positive AC by the pilot SVM; the runtime deterministic constraint parser now handles this separately. Neither candidate is eligible for deployment.

Actual local inference load, median/P95 latency, process peak memory and artifact size are recorded in models/benchmarks/phase2-pilot-inference.json. Full training-only per-class reports are in evaluation.json; training-only confusion matrices are not yet emitted for the pilot; the combined comparison report is models/benchmarks/phase2-comparison.json. No validation or independent-test scores are reported. Benchmarks ran on the previously recorded 12-logical-CPU/32-GiB Windows host; peak memory is cumulative process memory, not isolated model allocation.

## Functional changes

Strengthened AC/non-AC and sleeper/seater negation, contradictory preference rejection, negated destination exclusion and DB-category exclusions. Existing exact aliases remain authoritative. Added a local SVM adapter gated on an ACTIVE, approved, independently evaluated registry descriptor with validation-derived threshold and a matching checkpoint checksum. The default continues using DB deterministic rules because no candidate meets those conditions. SVM margins are labelled decision margins rather than probabilities. A lifecycle gate rejects promotion without independent reports and documented dataset/metric/offline evidence. No automatic promotion occurred.
